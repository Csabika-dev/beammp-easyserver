🧰What do I need to host a server?Getting started✓ Answered
BEasyServer team
  • A computer that stays on while you play: any 64-bit Windows 10/11 PC, or Linux (Ubuntu, Linux Mint, Debian, also a Raspberry Pi 4/5 with a 64-bit system). An old laptop is fine for a group of friends.
  • A free BeamMP AuthKey (see the next question).
  • Your own copy of BeamNG.drive to play. The server itself is free.

Upload speed matters more than the processor: every player downloads your mods from you.

🔑Where do I get the AuthKey?Getting started✓ Answered
BEasyServer team
  1. Go to keymaster.beammp.com and log in with Discord.
  2. Click Keys, then +, and give it any name.
  3. Copy the key and paste it into the installer, or later under Config → AuthKey.

Without a key the server still works on your home network, it just isn't in the public server list. One key per public server.

🖥️Should I use Windows or Linux?Getting started✓ Answered
BEasyServer team

Playing on the same PC you host on? Windows is the easiest: download the zip, double-click Install-BeamMP-Server.bat.

A spare computer just for the server? Linux is better. The server runs in the background, starts by itself when the computer boots, restarts after a crash, and with laptop mode keeps running with the lid closed. One command installs everything.

⬆️How do I update EasyServer and the BeamMP server?Getting started✓ Answered
BEasyServer team
  • EasyServer itself: the dashboard's Updates page. On Windows you can also run the newest installer over the old one; your settings are kept.
  • The BeamMP server: Config → Restarts & updates → install BeamMP updates updates it automatically at the scheduled restart. By hand: beammp update on Linux, Update-BeamMP-Server.bat on Windows.
🔍My server doesn't show up in the BeamMP server listJoining & network✓ Answered
BEasyServer team
  1. Config → AuthKey must be filled in.
  2. Config → Private must be off. The "Most secure" and "Friends only" presets hide the server on purpose.
  3. The port must be reachable from the internet (see the next question).
  4. Give it a minute or two after starting.

Health → Check again checks all of this and says which one is wrong.

🌍Friends on my Wi-Fi can join, but friends outside my home can'tJoining & network most asked✓ Answered
BEasyServer team

Your router has to let them in. This is a one-time setting:

  1. In your router, give the server computer a fixed address (often called DHCP reservation or static lease).
  2. Forward port 30814, TCP and UDP, to that computer. Search for "your router model port forwarding" for the exact menu.
  3. In the dashboard: Health → Full check. "Reachable from the internet" should be green.

Still red? Some internet providers share one address between many homes (CGNAT), so port forwarding can't work. The Health page tells you when that's the case: ask your provider for a public IPv4 address, or use a relay (Settings → Hide your IP).

🚫One specific player can't joinJoining & network✓ Answered
BEasyServer team

Health → Someone can't join? → type their BeamMP name → Check. It reads their last attempt and says why it failed: banned, not on the invite list, maintenance, guests blocked, anti-bot code, too many players from one connection, server full, and so on, with the fix.

Refused players also show up under Config → Who can join → Recently refused with a + allow button.

🔒How do I put a password on my server / make it friends-only?Joining & network✓ Answered
BEasyServer team

BeamMP has no join password, so EasyServer uses an invite list instead:

  1. Config → Who can join: turn on the list and type your friends' BeamMP usernames, one per line.
  2. Save list. It works right away, no restart.

Everyone else gets an "invite-only" message. The quickest way is the Most secure or Friends only preset under Config → Security presets. With the Discord bot: /whitelist add name.

🔁My home IP address keeps changingJoining & network✓ Answered
BEasyServer team

Set up a free fixed name: Settings → Fixed address (DuckDNS). Friends then connect to yourname.duckdns.org, and it keeps working when the address changes. Public servers don't need this: the server list always has the current address.

🛡️Can players see my home IP? What about DDoS?Joining & network✓ Answered
BEasyServer team

Players connect to your server, so yes, they can find the address, like with any self-hosted game server. If that worries you, Settings → Hide your IP sends players through a relay, and flood protection is part of the Most secure and Public but safe presets. See Protect your IP.

📦How do I add mods?Mods & maps✓ Answered
BEasyServer team
  1. Open Mods in the dashboard and drag the mod .zip files onto the page.
  2. Each one is virus-checked first. The server restarts about 15 seconds later (on Windows, press Restart). That disconnects players, so add mods when it's quiet.
  3. Map mods get a map: badge. Click Use map to play it.

Players don't install anything: BeamMP downloads the mods for them when they join. Also possible: the Drop BeamMP Mods Here desktop icon (Windows), the BeamMP-Mods folder or beammp addmod file.zip (Linux).

🐢Joining takes forever because of the mod downloadMods & maps✓ Answered
BEasyServer team
  • Turn on Light mode on the Mods page: players only download the map that's being played. Other map mods come back by themselves when you switch to their map.
  • Remove mods nobody uses. The card at the top of the Mods page shows the total download.
  • Friends on slow internet can get a modpack (Mods → Modpack) and copy the files into Documents\BeamNG.drive\mods\multiplayer before joining.

Your upload speed is the limit here, so a big modpack is slow on any home connection.

🦠A mod was blocked by the virus check. Is it really dangerous?Mods & maps✓ Answered
BEasyServer team

EasyServer blocks mods that contain programs, disguised files or zip bombs, or that Microsoft Defender, ClamAV or VirusTotal flag. A normal BeamNG mod is only car, map and script files, so a blocked mod contains something a mod shouldn't. The reason is shown next to it.

Blocked files never reach the server or your players. Download the mod again from the official BeamNG repository instead of a reupload site.

🗺️How do I change the map, or let players vote?Mods & maps✓ Answered
BEasyServer team
  • Now: Overview → Map, pick one, confirm. The server restarts on the new map.
  • Vote: Config → Map vote, tick the allowed maps. Players type /vote in the game chat.
  • Automatically: Config → Map rotation (every 1-24 hours) or Config → Events ("Friday drift night").
🔐I forgot the dashboard password / lost my phone for two-step loginDashboard & login✓ Answered
BEasyServer team
  • Windows: double-click Reset-Dashboard-Login.bat in the EasyServer folder.
  • Linux: sudo beammp reset-login

Then open the dashboard on the server computer and choose a new password. Two-step login is turned off, so set it up again with your new phone.

⚠️The browser says "connection reset" or "not secure"Dashboard & login✓ Answered
BEasyServer team

"Connection reset": HTTPS is on, but you opened an http:// address. Use https://, or update to 1.12.1 or newer, which sends you there automatically.

"Not secure" / certificate warning: normal the first time. Your dashboard makes its own certificate, so the browser doesn't know it yet. Compare the fingerprint shown in Settings with the one in the browser warning, then continue. The Android app remembers it for you.

📱Can I manage the server from my phone, or from outside my home?Dashboard & login✓ Answered
BEasyServer team

At home: open http://<server-ip>:30815 on your phone, or install the Android app (BeamMP-EasyServer.apk from the latest release) and scan the QR code under Settings → Phone app. iPhone: Safari → Share → Add to Home Screen.

From anywhere: turn on HTTPS and two-step login, use a password of 12+ characters, then Settings → Access from the internet and forward port 30815 (TCP).

✅Can it remember my password so I don't log in every time?Dashboard & login✓ Answered
BEasyServer team

Yes (version 1.12.1 and newer). Turn on Stay logged in on this device on the login page. That device then logs in by itself for 30 days after the last visit, also after restarts. Your browser's password manager also offers to save the password.

Lost a phone? Settings → Remembered devices → Forget.

👥How do I give friends access to help moderate?Dashboard & login✓ Answered
BEasyServer team

Settings → Users & roles: name, role, password → Add.

  • Viewer: look, change nothing
  • Moderator: kick, mute, ban, invite list, restart, maintenance
  • Admin: everything except users, passwords and internet access

For in-game moderation only, add their BeamMP names under Config → Moderation & anti-bot → Admins. They can then use /kick, /ban and /mute in the game chat.

🤖How do I set up the Discord bot?Discord & alerts✓ Answered
BEasyServer team
  1. discord.com/developers/applications → New Application.
  2. Installation → Install Link: None → save.
  3. Bot → turn Public Bot off and Message Content Intent on (for the chat bridge) → Reset Token → copy.
  4. Dashboard: Settings → Discord bot → paste the token, turn it on, Save. When it says Online, click Add the bot to your Discord.
  5. Type /status in Discord.

Never share the bot token with anyone. If it leaks, press Reset Token again.

⌨️The bot is online but the slash commands don't show upDiscord & alerts✓ Answered
BEasyServer team
  • New commands can take a minute. Restart Discord (Ctrl+R on PC).
  • Check Settings → Discord bot → Discord server the bot answers in is set to your server.
  • /start, /stop, /restart and /whitelist only appear for people with Manage Server, or the Discord users you allowed.
🔔Can I get a notification when the server crashes or someone joins?Discord & alerts✓ Answered
BEasyServer team

Yes, on your phone (free ntfy app, Settings → Phone app), in Discord, Telegram, Slack and other apps, or by email. Choose what you hear about under Notify me about. Config → Join alerts posts when chosen players join.

💥The server keeps crashing or laggingProblems✓ Answered
BEasyServer team
  1. Logs → Explain the whole log lists every error in plain English, including broken mods and running out of memory.
  2. Health shows memory and disk, and Settings → Computer load has 24-hour graphs.
  3. On an older computer, use the Weak computer preset, lower Max cars and turn on light mode.

A crashed server restarts by itself, and you're told if crash notifications are on.

↩️I changed a setting and now something is brokenProblems✓ Answered
BEasyServer team

Config → What changed? keeps the last 40 versions of your config, with who changed what. Compare with now shows the difference, and Restore goes back. Your AuthKey is kept, and you can undo the undo.

🌙Do I have to keep the computer on 24/7?Problems✓ Answered
BEasyServer team

No. Settings → Sleep & wake-up puts it to sleep when nobody has played for a while and wakes it before events. With Wake-on-LAN (network cable needed) friends can wake it with /start in Discord or the Wake up button in the app. The compatibility score lists what still has to be set.

💾How do I move my server to a new computer?Problems✓ Answered
BEasyServer team
  1. Old computer: Settings → Backup / move to another computer → Export settings + mods.
  2. Install EasyServer on the new one, then Import… that file.
  3. Paste your AuthKey again: keys and passwords are never put in exports.

Nightly backups are on by default, and the last 7 can be downloaded any time.

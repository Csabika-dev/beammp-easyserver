# Security policy

## Reporting a security bug

If you found a security problem in BeamMP EasyServer, please **don't open a public issue**. Report it privately so it can be fixed before anyone else learns about it:

- **GitHub:** use the **"Report a vulnerability"** button on the [Security tab](https://github.com/Csabika-dev/beammp-easyserver/security) of this repository, or
- **Email:** beammp.easyserver.security@gmail.com

Please include:

- what the problem is and what an attacker could do with it
- steps to reproduce it (the EasyServer version, Windows or Linux, settings you used)
- if you have one, a suggested fix

I'll reply within about a week. Once the fix is released, I'm happy to credit you in the changelog (tell me if you'd rather stay anonymous).

## Supported versions

Only the latest release gets security fixes. If you're on an older version, update by running the installer from the [latest release](https://github.com/Csabika-dev/beammp-easyserver/releases/latest) again; your settings, mods and keys are kept.
